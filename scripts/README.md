# Streamlit Dashboard Notes

This folder is reserved for helper scripts or lightweight notes that support the dashboard workflow.

## Run locally

```bash
streamlit run app/main.py
```

## Expected cleaned files

Place cleaned CSVs in `data/`, for example:

- `data/benin_clean.csv`
- `data/sierraleone_clean.csv`
- `data/togo_clean.csv`

## Streamlit Community Cloud

1. Push the repository to GitHub.
2. Create a new app on Streamlit Community Cloud.
3. Set the entry point to `app/main.py`.
4. Deploy.
